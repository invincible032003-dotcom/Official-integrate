# Book pp. 105-147 · NSO Vision 2024
@source Book · set B09
@group book
! Vision 2024 = **real-time data for policy** + stronger dissemination. Coordination runs **lateral** (across ministries) and **vertical** (Centre-State).
! Timeline: **UN FPOS 2014 → India adopts 2016 → NQAF 2018**. NQAF-certified divisions: **NAD, PSD, SDRD**.
! HLG-MOS models (UNECE): **GSBPM** (process: Specify, Design, Build, Collect, Process, Analyse, Disseminate, Evaluate), **GSIM** (information), **CSPA** (architecture), **GAMSO** (activity).
- Exchange standards: **SDMX** for aggregate data, **DDI** for microdata.
! Strategy pillars: **I Institutions** (NPOS, an NSC Act), **II Infrastructure** (IT, an integrated building), **III People**.
- **NIIP** = one integrated portal with common metadata and a real-time dashboard. Soft integration via a **data lake**.
! Registries: **P**erson, **B**usiness (NSBR = EC + administrative registers; business register number piloted in **Rajasthan**), **L**ocation. CAPI started in PLFS; **GSS** = one IT platform for all surveys.
- 7th EC carried out through **CSCs (MeitY)**. **NSSTA** is MoSPI's academy. Enumerator skilling via **MSDE, NSDC** and a Sector Skill Council. The inter-ministerial committee meets **quarterly**.
- Targets: **+25 indicators a year (100+ by year 5)**; **NIF** at national level, **SIF** at State level. A **clearing house** avoids duplicate data collection. The Vision runs from the 7th EC and plans the 8th.
